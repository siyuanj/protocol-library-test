# Protocol Atlas public preview

This is the deployable GitHub Pages site for a metadata-only protocol catalogue.

It contains a hand-selected starting set of 60 classic-method records from local curation sessions:

- 28 categories marked complete in their source session result;
- 2 explicitly labeled follow-up entries from incomplete categories;
- 30 explicitly labeled peer-screening candidates, including 21 additional local representatives and 9 classic method variants selected from the local screening queue;
- no procedure text, tables, images, video, PDFs, attachments, or processed LabRecord protocols.

Every card exposes its source, attribution, DOI where available, and recorded license label. When local curation captured license evidence, the card links to it; otherwise it directs reviewers back to the source. A displayed source-level license is not a replacement for checking the cited original paper, individual version, embedded third-party material, source terms, or laboratory safety requirements.

`protocols.js` is maintained manually for public presentation; crawlers never write to this folder.
